# acton-ai-macros

Procedural macros for [acton-ai](https://crates.io/crates/acton-ai).

This crate exists only to back the `#[tool]` attribute. **Depend on `acton-ai`
instead of on this crate directly** — the macro expands to `::acton_ai::…`
paths and will not compile without it. `acton-ai` re-exports the macro under
its default `derive` feature:

```rust
use acton_ai::prelude::*;

/// Adds two numbers and returns the sum.
#[tool]
async fn add(a: i64, b: i64) -> Result<serde_json::Value, ToolError> {
    Ok(serde_json::json!({ "sum": a + b }))
}

let response = runtime
    .prompt("What is 42 + 17?")
    .add_tool(Add)          // PascalCase unit struct, generated by the macro
    .collect()
    .await?;
```

The tool's name comes from the function name, its description from the doc
comment, and its JSON Schema from the parameter list. See the [`acton-ai`
documentation](https://docs.rs/acton-ai) for the full contract.

## Release order

This crate must be published **before** `acton-ai`, which depends on it.
